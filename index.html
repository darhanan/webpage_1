About Me

Hello! My name is Darkhan and I am a first-year IT student, and I also work as a product designer five days a week. I am learning how the web is built, starting with HTML for structure and CSS for presentation. This page is my very first hand-written webpage: every tag and every style rule here was typed by me, without any framework.

What I am studying right now

At the moment I am focused on semantic HTML, the CSS box model and writing selectors that are easy to read. Because I design interfaces at work, being able to build them in code myself is exactly the skill I want. My goal for this semester is to be able to rebuild any simple layout from a screenshot using only my own CSS.
